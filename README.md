## Project Title: AI-Powered Financial Health Assessment for SMEs ##

## Description: 
This project is a full-stack web application that helps small and medium enterprises (SMEs) assess their financial health using key financial metrics such as revenue, expenses, debt, and cash flow. The system calculates financial indicators including net profit, profit margin, debt ratio, and a composite financial health score.

Based on these metrics, the application uses an AI language model (Groq LLaMA) to generate personalized, actionable financial insights and recommendations. This helps business owners understand risks, improve cash flow management, and make informed financial decisions.

## Tech Stack: ##
Frontend: React.js (Netlify)
Backend: Flask API (Render)
AI: Groq LLaMA model

## Problem Solved: ##
Many SMEs lack access to professional financial advisory services. This solution provides an affordable, AI-driven financial analysis tool that delivers instant insights and recommendations.
